# Windows 到 Windows 或 macOS 的记录同步

两台设备都需要运行支持此功能的 TeyvatGuide，并能访问同一个 WebDAV 目录。Windows 可手动上传和拉取；macOS 只拉取。应用不会自动同步，也不会搭建或配置服务器。

1. 在作为发送端的 Windows 上打开「设置 → 数据相关 → 跨设备同步」，填写 WebDAV **目录**地址、用户名和密码，点击「上传记录」。记下成功后显示的快照 ID，可用于恢复历史快照。
2. 在接收端 Windows 或 Mac 打开同一面板，指向同一个目录，点击「拉取记录」。历史 ID 留空拉取最新快照，填入 ID 则拉取该历史快照。接收端只读 WebDAV，可以使用只读账号。
3. 打开祈愿或高难挑战页面查看导入记录。未登录米游社也可以选择已有记录的游戏 UID。

Windows 上传前先只读检查 WebDAV 连接；连接通过后才校验本机记录。若提示 `SYNC_INVALID` 并附带表与字段，可用这条提示排查旧记录格式，不需要提供数据库。记录校验失败时不会上传快照或写入 WebDAV。

只传输原神祈愿、深境螺旋、幻想真境剧诗、幽境危战记录及其游戏 UID，不传输千星奇域颂愿、米游社 Cookie、胡桃云凭据、应用设置或剧诗中的外部配队链接。WebDAV 密码不会保存。建议用私有目录和 HTTPS；应用不会跳过证书校验。有意使用 HTTP 时需要手动确认明文风险。快照未额外加密，服务端和有目录权限的人可以读取记录。

接收端只插入缺少的记录；同 ID 的祈愿或同 UID、同一期次的高难记录会按上传规则比较，不会因旧字段格式或占位图误报冲突。内容实际不同时保留本机版本，并提示跳过数量。拉取后可在原面板展开「查看冲突详情」，对照记录类别、快照的游戏 UID、祈愿 ID 或期次、时间，以及不同的字段。可展示的简单值（例如已知的祈愿名称、星数）会标出本机与快照的值；详细战绩等复杂内容只列出不同的项目。最多列出 20 条明细，超出时提示其余条数；明细不会改变本机记录，也不写入快照。

发送端的删除不会传播到接收端。无效、超限或不兼容的快照不会写入本机数据库；单个快照上限为 16 MiB。本机无关的大记录不影响拉取，实际需要比较的同键记录仍受字段大小限制。

上传时，已识别的官方战绩与养成计算器静态图片保持原地址；不支持的图片会在快照中换成本地占位图。旧非月谕剧诗缺少的月谕字段会补为未参加，数字完成时间转成相同的十进制字符串；现有月谕成绩不推断、不改写。祝福中的游戏词条及其说明会保留，界面只显示词条文字，不创建外部链接。缺少最佳成绩字段的旧危战记录会标记为无最佳成绩，不会丢弃已有场次。以上处理不修改 Windows 原始记录。缺少整个详情或其他无法安全识别的旧格式仍会拒绝上传，不会截断或跳过整条记录。

旧剧诗战斗统计中缺少的可选角色摘要（例如击败最多敌人的角色）在快照中表示为无值，缺少的最短用时队伍表示为空列表。已有战斗统计照常保留；缺少整个详情或必要统计仍会拒绝上传。危战摘要中以数字记录的 DPS 会在快照中转换为 v1 接收器支持的文本表示，已有 DPS 文本原样保留。

## 历史记录与本地备份

从 [v0.9.1](https://github.com/BTMuli/TeyvatGuide/commit/f2c5051a23d95eef230015b47a9daa0fc4d8aa31) 到 [v0.14.1](https://github.com/BTMuli/TeyvatGuide/commit/1b1da1dacd51e23db7705ffea48fea4695b8c7b0)，这四张表的正式列定义和主键相同。需要适配的是存量行的旧写法，不是按应用版本重建数据库。同步参考当前页面和备份实际使用的业务字段；它不是整份用户备份，不传账号等数据，也不沿用恢复时的同键覆盖。

| 本机记录                                 | 发布和判定相同记录时的处理                                                                                                                                                             |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 旧祈愿写入器遗留字面 `"null"`            | 可空的道具 ID、物品类型、星级按空值处理；数量缺省沿用[参数化写入器](https://github.com/BTMuli/TeyvatGuide/commit/9be8c78debaa7521e71b9c1b119de62042cdcf3d)的 `1`。不将其他文本当空值。 |
| 深渊的上下半战斗或半场怪物列表为 `null`  | 页面与省略字段的显示相同，所以用省略表示；参战角色、星数和 `skippedFloor` 等实际值保留。当前本地备份的恢复不写跳层字段，不能反推已丢失的跳层值。                                       |
| 剧诗最短用时队伍为 `null` 或缺省         | 页面与空队伍列表都显示无数据，v1 使用 `[]`；不会补造已有战斗统计或整个详情。                                                                                                           |
| 当前危战页面和备份可读取含额外字段的战绩 | 本机允许保留这些字段；同步只提取 v1 在对应层识别的业务字段，保留已知队伍、成绩和数组顺序，不转传附加内容。                                                                             |

这些转换只发生在本机记录的内存副本，既不回写原库，也不放宽外部 v1 快照的校验。当前应用会隔离的缺失危战详情不凭空补造；无法在现有 v1 中保真的实际成绩不会被取整或截断。

## 版本兼容

同步快照使用固定的 v1 格式，不复制 SQLite 的建表语句，也不随应用版本或数据库列顺序变化。支持这份 v1 格式的两端可以使用不同的应用版本。最早的同步试验包不认识后来补齐的剧诗词条等数据，仍需升级，不能用本功能兼容没有同步入口的旧版应用。

- **数据库新增普通列**：列不在同步白名单内时，不上传它。目标库有新增可空列或带非空默认值的必填列时，新记录由 SQLite 填默认值；本机已有记录和扩展字段不会被改写。
- **已知旧深渊表**：没有 `skippedFloor` 列时按无值导出。旧目标库只能接收该字段为空的快照；有实际跳层信息时会拒绝整包，不会把该值丢掉。
- **不能无损处理的结构**：例如字段改名、主键或列类型变化、新增必填列却无可用默认值、旧库缺少危战详情，提示 `SYNC_SCHEMA` 或 `SYNC_LEGACY_CHALLENGE`。先备份并用新版应用升级本地数据库；缺失战绩详情不能靠同步生成。同步本身不会迁移数据库。
- **不支持的快照版本**：记录或 WebDAV 清单有独立的版本错误 `SYNC_VERSION_UNSUPPORTED` / `WEBDAV_VERSION_UNSUPPORTED`。升级对应设备后重试，或选择仍受支持的历史快照。发布端不会替换无法识别版本的最新清单。

如果以后需要改变同步字段的含义或结构，应新建记录格式与清单版本，并保留 v1 解码和明确的迁移规则；只改本地表结构不应改发布格式。

## WebDAV 目录与恢复

目录需预先创建，并支持 GET、条件 PUT 及强 ETag。上传保留历史快照，不自动清理；同一目录只应由一台 Windows 发布，不要用来存其他内容。若中断导致最新指针不可读，可在接收端输入先前记下的快照 ID，或从目录中 `teyvatguide-sync-<ID>.manifest.json` 的文件名找到 ID。恢复只读，不会修复服务端的最新指针。
