# Windows → macOS 记录同步

两台设备都需要运行支持此功能的 TeyvatGuide，并能访问同一个 WebDAV 目录。目录可以由自己部署的服务提供；应用不会搭建或配置服务器。

1. 在 Windows 的「设置 → 数据相关 → 跨设备同步」填写 WebDAV **目录**地址、用户名和密码，点击「上传记录」。可以记下成功后显示的快照 ID。
2. 在 Mac 打开同一面板，指向同一个目录，点击「从 Windows 同步」。Mac 不会向 WebDAV 写入。服务支持按目录授权时，Mac 可以使用只读账号。
3. 打开祈愿或高难挑战页面查看导入记录。未登录米游社也可以选择已有记录的游戏 UID。

Windows 上传前先只读检查 WebDAV 连接；连接通过后才校验本机记录。若提示 `SYNC_INVALID` 并附带表与字段，可用这条提示排查旧记录格式，不需要提供数据库。记录校验失败时不会上传快照或写入 WebDAV。

只传输原神祈愿、深境螺旋、幻想真境剧诗、幽境危战记录及其游戏 UID，不传输千星奇域颂愿、米游社 Cookie、胡桃云凭据、应用设置或剧诗中的外部配队链接。WebDAV 密码不会保存。建议用私有目录和 HTTPS；应用不会跳过证书校验。有意使用 HTTP 时需要手动确认明文风险。快照未额外加密，服务端和有目录权限的人可以读取记录。

Mac 只插入缺少的记录；同 ID 或同 UID、同一期次内容不同时保留本机版本，并提示跳过数量。Windows 的删除不会传播到 Mac。无效、超限或不兼容的快照不会写入本机数据库；单个快照上限为 16 MiB。

上传时，已识别的官方战绩与养成计算器静态图片保持原地址；不支持的图片会在快照中换成本地占位图。旧非月谕剧诗缺少的月谕字段会补为未参加，数字完成时间转成相同的十进制字符串；现有月谕成绩不推断、不改写。祝福中的游戏词条及其说明会保留，界面只显示词条文字，不创建外部链接。缺少最佳成绩字段的旧危战记录会标记为无最佳成绩，不会丢弃已有场次。以上处理不修改 Windows 原始记录。缺少整个详情或其他无法安全识别的旧格式仍会拒绝上传，不会截断或跳过整条记录。

两端应使用相同的同步测试版本。较早的严格接收端不认识新增的游戏词条元数据，不能混用旧 Mac 测试包。

目录需预先创建，并支持 GET、条件 PUT 及强 ETag。上传保留历史快照，不自动清理；同一目录只应由一台 Windows 发布，不要用来存其他内容。若中断导致最新指针不可读，可在 Mac 输入先前记下的快照 ID，或从目录中 `teyvatguide-sync-<ID>.manifest.json` 的文件名找到 ID。恢复只读，不会修复服务端的最新指针。
